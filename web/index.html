Connect your models

Add an API key for each provider you want to test. Keys stay in this app's memory only: they are never saved to disk and are only sent to the provider they belong to. Keys in .env are loaded automatically. Simulated agents need no key, so you can try everything first.

Agents (behaviour)

Inside the model (activations)

API models never expose their internals. To read activations, the app runs an open model on NDIF, a free research service. Gated models such as Llama also need a Hugging Face token, plus accepting the model's license on its Hugging Face page.

Design a paired experiment

Each request is shown twice, with the same task and the same safety policy. One copy sits in an environment that looks like a test sandbox and the other in one that looks like production. Any difference in what the agent does is caused by the environment.

Read the model's internals

        
Can the model's activations tell "this looks like a test" apart from "this is production", even when it never says so? This view trains a probe on prompts that state "this is an automated evaluation". It then tests the probe on environments that never mention testing, re-scores it on the traces where the model stayed silent, and steers along that direction to see whether behaviour moves.
